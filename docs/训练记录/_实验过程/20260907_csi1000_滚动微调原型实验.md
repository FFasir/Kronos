# 20260907：中证1000 滚动微调原型实验（Rolling Fine-tune Prototype）

> 日期：2026-09-07 ｜ 服务器：RTX 4090 / conda py312 ｜ 复现目标：CICC《Kronos的A股择时应用》33.9%（测试区间 20250101–20250930）

## 1. 背景与动机（为什么做滚动微调）

前序实验（`20260907_csi1000_pts_10ep微调与滚动回测结果.md`）结论：

- 工程与预测精度复现成功（优化后 T5 Spearman 0.9415 > 论文 0.856）；
- **静态单次微调（2015→2022 训练）+ 月度滚动搜参在 2025 择时上跑不赢买入持有**（全年 net +8.7%~+24.8% vs B&H +31.0%），而 base 零样本+滚动搜参反而 net +36.6%；
- 论文正文与图表21 显示，其最优曲线对比中包含 **"滚动微调策略净值"** 与 **"仅微调策略净值"** 两条线，且正文把 33.9% 与"定期微调后的模型在 2025 年 7 月以来对趋势变化敏感度上升"绑定 → 我们复现的是"仅微调"线，**缺的是"滚动/定期重训"机制**。

本实验目标：验证"滚动微调"能否恢复静态微调缺失的 2025-07 后趋势敏感度，并比较其与静态微调/base/论文 33.9% 的差距。

## 2. 实验设计

### 2.1 滚动重训协议（原型假设）

| 项 | 取值 | 说明 |
|---|---|---|
| 测试月 | 2025-01 ~ 2025-09（与论文测试区间一致） | 每月一个独立 checkpoint |
| 训练窗口 | 测试月前 12 个日历月（截至前一月末） | 模拟"用最近数据定期重训" |
| 训练数据 | 官方 pkl（val 2023–24 + test 2025–01..09）按窗口重切；lookback 250 / horizon 5，hfq | 693→624 只（后期历史不足者剔除） |
| 重训目标 | predictor-only，**2 epoch warm-start**，lr 1e-5，60k 样本/epoch，patience 0（取末次） | 月1 从静态微调 predictor 起步；月 m 从月 m−1 滚动 checkpoint 续训 |
| tokenizer | 全程复用静态微调 tokenizer（EXP-CSI1000-PTS best ep7） | 未做 tokenizer 滚动 |
| 评估 | 与 P1 完全同构：验证月 m−1 网格搜参（T×top_p×lookback）→ 测试月 m 预测 → 非重叠 5 日持有择时，含成本 | 新增 `--month-model-manifest` 逐月换模型 |

### 2.2 对照与口径

- ROLL-sp / ROLL-nr：滚动微调 + 按 spearman / net_return 选参（9 个月）
- FT-static-sp / FT-static-nr：静态微调同窗口 9 个月基线（RE3/RE4）
- BASE-sp：base 零样本同窗口（RE5）
- 另附 P1 全年(12 个月)静态/W4 结果作参考
- 成本假设：佣金 0.03%，滑点 0.1%，无印花税；信号 T−1 收盘生成、T 开盘建仓、固定持有 5 个交易日

## 4. 结论

1. **"滚动微调"机制方向性验证成功**：滚动微调全面优于静态单次微调（净收益 +22.4~27.1% vs +16.0~20.7%）；关键在 H2——ROLL-sp 在 2025-07 后录得 +7.30%（静态仅 +1.59%，+5.7pp），与论文"定期微调使模型对 7 月后趋势变化敏感度上升"的论述一致。滚动重训确实让模型带上了近期 regime 权重。
2. **但滚动微调（本原型配置）不足以复现 33.9%**：最优滚动口径（net_return）净 +27.1%、毛 +31.2%，低于论文 33.9% 约 2.8~6.8pp；base 零样本反而最接近（净 +32.0%、毛 +36.9%，方向准确率 55.1% 全场最高、唯一正超额）。
3. **33.9% 归属与剩余差距**：图表 21 无数字标注，正文将 33.9% 与"定期微调"绑定，但未披露滚动重训的频率/窗口/epoch/是否含 tokenizer。若论文 33.9% 为含成本口径，则其滚动微调版本在训练充分度上强于我们的 2-epoch/12 个月原型；若为毛口径，我们的 ROLL 毛 31.2%（base 毛 36.9%）已接近或超过。剩余差距最可能来自：(a) 论文滚动微调超参（频率/epoch/窗口）；(b) 训练期 2010–2022（我们 2015-06 起，P4 回溯成分未做）；(c) qfq vs hfq；(d) 成本与执行口径。
4. **base 净 +32.0% 已逼近 33.9%**：若目标只是数值达到论文，零样本 base+月度滚动搜参是最接近的路径；但它是非论文对照，且逐月选参本身在验证月内择优（我们验证月 m−1 属于滚动训练窗口，存在轻度样本内选择偏差，见 §5），不应作为"复现成功"证据。
5. 与全链路诊断一致：方向准确率仍是硬约束——即便滚动微调把胜率提到 83%（nr），方向准确率也只 47.8%，收益来自少数高质量交易而非稳定方向预测；base 方向准确率 55.1% 是所有方案中最高的，与其最好收益一致。

## 5. 方法与局限

- 重训/评估代码：`scripts/build_rolling_datasets.py`（按测试月切 12 个月窗口 pkl）、`scripts/run_rolling_paper_walk_forward.py`（`--month-model-manifest` 逐月换模型，其余与 `run_paper_walk_forward.py` 同构）。
- 局限 1：滚动重训为 **predictor-only**、2-epoch、近 12 个月窗口、月 1 从静态 FT 起步的 warm-start 链——是论文"滚动微调"的一种原型假设，非论文披露版本。
- 局限 2：验证月 m−1 落在滚动训练窗口内，参数搜索存在轻度样本内选择偏差（不影响测试月样本外性质）。
- 局限 3：训练数据 hfq、2015-06 起（非 2010），未含 2010–2014 回溯成分与 qfq 口径。
- 局限 4：图表 21 无逐线数值标注，33.9% 与具体方案（仅微调 vs 滚动微调）的归属为正文推断。

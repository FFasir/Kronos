## ① 概率信号 vs 均值（9 个月净收益）
| 信号 | 净 | 交易数 |
|---|---|---|
| 均值 >0.5%（脚本内基线） | +27.3% | 15 |
| P(涨>0) ≥0.4 | **+30.9%** | 21 |
| P(涨>0) ≥0.5 | +20.7% | 19 |
| P(涨>0.5%) ≥0.3/0.5 | +19.7%/+8.1% | 20/16 |
| 标准管线 base+Spearman（对照） | +32.0% | 14 |

核对：与标准管线差异来自 2025-05 验证月选参并列(spearman≈−0.118)的微小舍入 → 选中不同 top_p/lookback；仅该月 14 行预测不同。结论：**概率信号没有超过均值/水平管线**。

## ③ 信号体检（138 信号日，2025 牛市样本 base rate 68.1%）
- 模型方向准确率 52.2%（均值）、P涨0.5 信号 39.1%、动量符号 56.5% —— **均低于"永远看多"68.1%**；
- 收益率级 IC：P涨 0.24 / 均值 0.21 / P涨0.5 0.10 —— 有微弱正信息（非零）；
- H1 方向准确率 55.2%（base 56.3%）基本持平；**H2（7 月后）47.1% vs base rate 88.2% —— 趋势市方向判断明显失效**；
- 上/下行 regime 拆分：方向准确率均低于各自 base rate。

## 结论
1. base 采样概率信号 ≈ 均值信号；方向能力仍弱，收益高值主要来自水平/选参，而非方向；
2. 作为"方向信号"，base（任何推理形态）不合格——趋势段（H2）失效是主因；
3. 下一步（若目标是真方向/超 33.9%）：② 判别式方向头（分类/排序损失直接监督 5 日方向，配 LoRA 冻结主干）为治根因路线；④ 趋势 regime 叠加为补 H2 的轻量对照。

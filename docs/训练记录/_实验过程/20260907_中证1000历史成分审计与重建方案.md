# 中证1000历史成分审计与重建方案（2026-09-07）

> 状态：成分审计完成；重建待服务器执行
> 目标：核对 `1000成分股/` 历史成分快照是否可用于无幸存者偏差的 Kronos 微调复现，并给出覆盖补齐方案与重建命令。

## 1. 审计结论：成分信息本身正确（2015-06-15 起）

对 `1000成分股/中证1000(000852.SH)-YY-N.xlsx`（22 个文件，2015-1 ~ 2025-2）逐文件解析并做 4 层独立校验：

| 校验层 | 结果 |
| --- | --- |
| 结构 | 每期恰好 1000 只、无重复、仅 SH/SZ、权重和 0.9998~1.0049、单票权重峰值 0.4%~0.9%（符合编制规则） |
| 更替节奏 | 相邻两期重合 893~900 只（每半年调换 ~100 只 ≈ 官方"每次调整不超过 10%"规则）；2015H1→2025H2 跨 10.5 年仅重合 210 只 |
| 生效日期 | 每期 `纳入日期` 最大值 = 该期定期调整生效日，22 个日期全部命中"每年 6 月/12 月第二个周五后的首个交易日"独立推算（含 2021-06-15 端午顺延） |
| 行情列 | 用腾讯不复权日线锚定各期收盘价 → 各期行情为**该半年度期末交易日**（2019H1→06-28、H2→12-29/12-31 等；停牌股为停牌前最后价）；各期均价走势与真实市场周期吻合（2018H2 谷底 10.8 元 → 2021H2 顶 31.2 元），排除"今日价格回填" |

**结论：22 个文件是真实的历史时点成分表，可用于把 2015-06-15 之后的微调训练期改为无幸存者偏差口径。**

### 使用注意（重要）

1. **覆盖起点 = 2015-06-15**（最早一期生效日）。中证1000 于 2014-10-17 才发布，本批没有发行样本与 2014-12 首次调样的独立文件。
2. **简称列是 2026-02 导出时的现名**（早期文件含"退市游久/ST西发/退市保千"等 2026 年名称）。ST/退市过滤必须用代码规则，禁止用该列文本过滤。
3. 此前 EXP-20260715-01 用的是 **2026-07-14 当前成分快照回填 2010-2022**（幸存者偏差），与本次文件是两套口径；本次文件才是接近报告口径的输入。

## 2. 覆盖缺口与获取结论

| 区间 | 性质 | 可获取性 |
| --- | --- | --- |
| 2010-01-01 ~ 2014-10-16 | 指数未发布；"历史成分"仅为 Wind/CSMAR 按现行方案的**回溯推算**（报告数据源） | 免费源无；需 Wind/CSMAR/Choice 导出或 Tushare `index_weight` 权限（账户此前被拒） |
| 2014-10-17 ~ 2015-06-14 | 官方发行样本 + 2014-12 首次调样 | csindex 官网当前只公开当期样本；2014 公告附件在官网内部分页，公开转载仅摘要；可尝试官网公告接口逆向或厂商导出 |

已实测封闭的路径：akshare（仅当期样本）、本机无 Tushare 且无 token、理杏仁 403、中证官网公告列表接口未定位、2014 新闻转载无完整名单。

**决策（2026-09-07 与负责人确认）**：放弃免费补 2010-2014；可选路径为
(a) 拿到 Wind/CSMAR/Choice 或 Tushare 权限后补全（推荐，唯一能对齐报告 13 年训练窗的路径）；
(b) 官方记录从 2014-10-17 起（需发行样本与 2014-12 调样附件，尚未获取）；
(c) **先用已审计的 2015-06-15 起名单重建**（本次落地采用，见下）。

## 4. 服务器重建命令（在 GPU 服务器，须先具备 data/source/daily_hfq.zip）

训练区间起点随数据可获取性调整；目前落到 2015-06-15。

```bash
cd ~/kronos-strategy

# 0) 上传成员文件到服务器
scp "1000成分股/_parsed/csi1000_historical_membership.csv" \
    root@your-server:~/kronos-strategy/data/raw/

# 1) 重建 Qlib（时点成员过滤，无幸存者偏差）
python scripts/build_qlib_data.py \
  --archive data/source/daily_hfq.zip \
  --historical-components data/raw/csi1000_historical_membership.csv \
  --output data/processed/qlib/cn_data_pts_2015 \
  --start 2015-06-15 --end 2025-09-30

# 2) 两阶段微调（Tokenizer→Predictor；config 默认值 = 论文图表16）
python scripts/run_official_finetune.py \
  --experiment-id EXP-20260907-PTS-2015 \
  --dataset-path data/official_processed_datasets_pts_2015 \
  --save-path models/official_finetune/EXP-20260907-PTS-2015 \
  --epochs 10 --batch-size 30 --train-samples 60000 --val-samples 6000 \
  --num-workers 4 --early-stopping-patience 3 \
  --lookback 250 --horizon 5

# 3) 论文滚动搜参 + 择时（图表17 网格；2025 测试期）
python scripts/run_paper_walk_forward.py \
  --start-month 2025-01 --end-month 2025-09 \
  --data data/raw/000852_中证1000_daily.csv \
  --tokenizer-path models/official_finetune/EXP-20260907-PTS-2015/tokenizer/checkpoints/best_model \
  --model-path models/official_finetune/EXP-20260907-PTS-2015/predictor/checkpoints/best_model \
  --device cuda --samples 10

# 4) 验收：Path A 加载 + best_model/summary.json + 记录 SHA256/口径
python scripts/load_kronos.py --path kronos --device cuda
```

**训练窗口口径变更声明（必须写入训练记录）**：本次重建训练期为 2015-06-15 ~ 2022-12-31（7.6 年），验证 2023-2024；比报告的 2010-2022（13 年）少约 5.4 年，差异源于官方成分记录起点与厂商回溯数据缺失。若后续补齐 2014-10-17 发行样本或 2010-2014 回溯成分，将 `--start` 提前并重跑本流程。
